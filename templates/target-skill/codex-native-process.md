# Codex-Native Skill Creation Process

Use this reference when the scaffold is being completed or revised by Codex-native agents.

1. Understanding the Skill with Concrete Examples.
2. Planning the Reusable Skill Contents.
3. Initializing the Skill.
4. Edit the Skill.
5. Validate the Skill.
6. Iterate.

## Completion Notes

- Keep `SKILL.md` compact and operational.
- Move heavy examples, rubrics, and templates into `references/`.
- Keep frontmatter to `name` and `description`.
- Make the description trigger-only and begin with `Use when`.
- Validate the skill folder before publishing.
